# OpenDev Elite v0.8.0 交付说明

2026-09-08。本版提高入选门槛，并重新整理登录页与工作台布局。本地正式服务已更新至 0.8.0。

## 质量筛选

新标准 `sop-2026-09-v3` 要求总分至少 80/100，每个维度至少 3/4 分：需求 20%、工程 25%、维护 20%、差异化 20%、可评测性 15%。评分须逐项引用依据；服务端重算加权总分，不接受客户端自报总分。

维护要求过去 365 天内至少两个不同日期的实质事实及两个不同来源。初始化、机器人更新和更新时间不能单独证明持续维护。新增差异化对照、可复现评测计划与质量暂缓条款，保留八类有依据的排除条件。低分或未知先暂缓，旧标准评估需重评，候选和历史保留。

评分记录用于判断是否投入评测，事实仍由评估人核查。入选之后依然需要第一轮技术复核、团队或自有 Agent 的真实体验和第二轮结论，才能联系作者。完整规则见 [入选标准](项目入选与排除标准.md)。

## 界面

- 登录页改为居中单表单，保留账号、密码、显示密码和语言切换；兼容登录收进“其他登录方式”。移除介绍、方案对比和合成演示区。
- 工作台按发现评测、建联支持、工作空间分组；调整字号、间距、表格和筛选区，概览优先显示当前待办。
- 标准页突出总分门槛、五项权重与评分锚点，其他条款可展开；评估表单按五个维度分组，实时算分，滚动时保留关闭和保存按钮。
- 项目评估显示服务端分数与单项明细，可展开来源；当前记录和历史均保留新增依据。中英文、手机和平板布局同步调整。

默认管理员仍为 OpenDev / 123456，已有密码不会在升级时被覆盖；没有公开注册或管理员创建入口。成员继续由管理员在后台创建。登录地址为 http://127.0.0.1:8765/#team-login。
