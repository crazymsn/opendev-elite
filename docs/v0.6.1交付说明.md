# OpenDev Elite v0.6.1 · 入选与排除标准深化

2026-09-07 已交付并升级本机工作台。程序版本 0.6.1，标准版本 sop-2026-09-v2；SQLite 保持 schema 6。

## 标准与工作流

- 支持开发者工具、面向真实用户的 AI 工具、Agent 基础设施，以及供 Agent 调用的应用。
- 五项入选前提：真实用户任务、AI/Agent 适配、核心评测入口、实质维护、归属/权限/风险可核查。
- 六类暂缓原因、八类排除原因，各自绑定可核对证据。未知事实先暂缓，不把单人、早期、零 Stars、API 封装或低频提交自动视为不合格。
- 维护信号需指向具体提交、发布或响应及其发生日期；90 天观察窗口并非淘汰线。
- 标准页和评估表单共用服务端目录；入选需补齐场景、入口和权限风险材料。条款与结论、停止维护和范围外状态必须一致。
- 按“实际验证后不成立”排除要求当前版本第二轮未通过及其关联的已完成产品体验；仅环境失败不能满足该条件。
- 旧标准评估保留并标记需重评，既有资金对账和复盘义务继续保留。系统核验证据结构，事实仍由负责人复核。

完整规则、典型边界及团队步骤见 [项目入选与排除标准](项目入选与排除标准.md)。API 必需字段变化见 [接口说明](v0.6档案与流程接口.md)。
