# OpenDev Elite v0.7.0 · 开发者档案与前期筛选

2026-09-08 已升级本机工作台。程序 0.7.0，标准 sop-2026-09-v2，SQLite schema 6。

## 本轮完成

- 新增“开发者与团队”：按稳定 GitHub ID 聚合跨仓库资料，区分个人账号与组织，提供搜索、类型/维护关系筛选、分页和项目入口。
- 候选贡献者与已确认维护者分明；账号同名不会自动合并。公开简介和机构标为账号自述，不推断个人能力或创业意愿。
- 访谈画像有原始访谈、来源项目、责任人与时间；可查历史联系、访谈、发放和复盘。正文与计数遵守原有角色权限，组织不会被计为个人。
- 同一作者拒绝联系的约束在其档案中显示，继续对关联的全部仓库生效。已有跨仓库防重复联系门槛保留。
- 团队待办新增分配负责人、补齐采集证据、入选评估、第一轮技术复核。每个项目只进入一个前期类别，调用共同的当前版本与审核条件。
- 暂缓、排除、结束、归档和禁用项目不自动进入前期队列；已发生的资金对账、领取和到账复盘义务仍优先。
- 访谈拒绝空白/布尔/数字等伪文本证据，拒绝重复或互相矛盾的画像标签。工程师与创业者可兼具；“待判断”只能单独使用。
- 中英文导航与原始访谈深链已验证；小高度窗口可滚动导航；切换到无访谈权限账号时不加载旧链接的私有记录。

入选政策继续覆盖真实用户 AI 工具、开发者工具、Agent 基础设施及供 Agent 调用的应用。五项前提、六类暂缓、八类排除与四项优先级详见 [入选标准](项目入选与排除标准.md)。更新时间、机械提交、低 Stars、单人或早期项目均不单独决定入选结果。
