## 已实现

- 采集版本、时间、许可标识、Fork 上游、版本不一致、目录截断与请求缺项。
- 最多六份文件预览，区分实现、测试、依赖、CI 和历史样本，绑定采集版本来源。预览最多每份 300 行及 12,000 字符，内部滚动；校验原始字节与记录的 Git blob SHA。
- 编码无效、内容过大、二进制、文件缺失和 SHA 不一致分别显示，不把异常当作成功预览。
- 提交、发布与 Issue/PR 摘要及来源，区分未采集、空列表、当前展示上限和来源后续分页。
- 中文和英文、键盘展开、移动端布局；外部代码和说明按被动文本显示，不执行脚本或渲染外部 HTML。

原始快照仍可展开核查。接口在既有项目详情中增加 `technical_evidence`，保持角色边界，无新数据库迁移，标准仍为 `sop-2026-09-v2`、schema 6。
