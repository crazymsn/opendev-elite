# OpenDev Elite v0.6.0 交付说明

2026-09-07：工作台逻辑、入选标准、中英双语、中文仓库档案和界面优化已交付。本机服务已升级为 **v0.6.0 / SQLite schema 6**，访问 `http://127.0.0.1:8765/`。默认管理员 **OpenDev / 123456** 登录已实际验证。

## 账户与团队使用

登录页提供账号密码、显示/隐藏密码、键盘提交和表单内错误反馈，已移除管理员创建及公开成员注册。管理员在“成员与权限 → 新增成员”开通账号并分配角色；支持本人改密、管理员重置、停用和权限调整。旧访问凭证保留为折叠兼容入口，普通成员无需领取 Token。初始管理员只创建一次，改密及升级不会重置。详细步骤见 [账号登录与成员管理](账号注册与授权.md)。

## 本次完成的改进

- 发现结果首先作为候选；依据方向、持续维护和来源评估入选。不按 Stars、地域或团队大小设置统一淘汰门槛。
- 服务端贯通技术复核、真实体验、第二轮产品复核、联系、访谈画像、独立赞助审批/执行、到账核对与复盘。换版本、重评、修改受众或证据过期使旧通过结论失效；已发生的财务义务仍显示待办。
- 详情按档案、入选、审核、体验、建联、访谈、赞助与复盘组织；历史分页、表单说明、状态和下一步统一。Credits 计划先展示接收对象、准确金额、活动和期限，原始请求放在可展开详情中。
- 中文 / English 可切换并记住偏好。原始证据、账号、代码和用户输入不自动改写。暖白、深绿界面统一排版，覆盖桌面与窄屏。
- 中文简介、README 阅读摘要和全文译文分别管理；源文更新会使旧译文失效。提供来源校验、网页编辑与 CLI 原子批量更新，见 [档案与流程接口](v0.6档案与流程接口.md)。

若回退，应先停止服务并保留当前 schema 6 数据，再恢复兼容的 schema 5 备份及旧运行时；不要直接用旧版操作 schema 6 数据库。正常服务已恢复采集，以上数量是发布快照，不承诺未来固定不变。

## 发布包与部署

发布文件在工作区 `artifacts/dist/v0.6.0/`：

- `github_sponsorship_worker-0.6.0-py3-none-any.whl`：Python 运行包与前端资源。
- `github_sponsorship_worker-0.6.0.tar.gz`：源码、测试、部署模板、操作文档及本次脱敏验收记录。
- `release-manifest.json`：文件 SHA-256、大小和验证边界。

源码包解压后进入包含 `compose.yaml` 的目录：

```sh
docker compose up -d
```

默认访问 `http://127.0.0.1:8780/`，使用 OpenDev / 123456。该命令自动从本地源码构建；数据卷持久化，后台启动后可用 `docker compose ps -a` 查看就绪状态。需可用 Docker Engine / Desktop Linux 后端和 Compose v2.20+。版本升级先备份并停止旧 API/Worker，完整步骤见 [Docker Compose 部署](DockerCompose部署.md)。
