## 产品范围

保留开发者赞助 SOP 全链路。将 friendly customer support CRM 的柔和视觉与结构应用于开发者关系管理：工单预览对应项目跟进，多渠道对应建联记录，AI 集成对应真实 Agent 体验协议与交互式流程帮助，方案比较解释支持方式及审批条件。未提供商业定价，不编造收费、客户评价、转化率或到账数字。

公开落地页和登录后工作台属于同一产品。公开示例明确标注，不读取真实候选；登录后使用服务端实际数据和角色权限。

## 设计系统

调用用户指定 ui-ux-pro-max 本地技能，GitHub 来源 nextlevelbuilder/ui-ux-pro-max-skill。生成规则位于 design-system/open-source-growth/MASTER.md，根据现有 Web 技术栈与用户视觉要求覆写，避免机械迁移为 React Native。

- 暖白背景、深松绿正文和主按钮、鼠尾草绿/杏色/淡紫辅助区域；状态同时有文字。
- 本地系统字体，不新增外网字体或 CDN；中文正文可读，标题层级明确。
- 落地页：宽幅导航、双列主视觉、跟进预览、功能、方案、FAQ、登录。工作台保留侧栏和角色信息。
- 4px 间距基线、12–24px 圆角、轻投影、至少 44px 按钮目标；不用低对比的拟物边界。
- 150–220ms 状态过渡，遵循 prefers-reduced-motion，无自动滚动或抢焦点动画。
- 区分已接入、可配置、流程示例和人工执行；不宣称自动联系或审批。
