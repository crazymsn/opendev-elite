## 本次审查推动修复的问题

| 问题 | 修复与复核 |
| --- | --- |
| 快速切换项目时，旧异步详情请求会覆盖 state.project | 前端将当前项目赋值移到 generation 校验后，避免旧请求污染新页面表单 |
| both 项目的分配表单错误默认 human | 默认值只在创建单对象体验时转换；实际浏览器分配表单保持 both |
| README 展示原始 API base64 对象 | 展示优先使用已经采集的 readme_text |
| 登出仅隐藏界面，旧内容留在隐藏 DOM | 清空 main、dialog 与身份信息及相关状态，递增 generation；桌面/移动退出后实际检查均为空 |
| Agent 提交接受任意 HTTP 200 JSON | ACK 必须绑定体验 ID，并确认一致的布尔 success 或 duplicate；错误 ACK 保留 submit_unknown，用原键恢复 |
| 运行中失去租约后仍持续执行到超时 | execute 的运行轮询执行租约回调，失效即杀掉客户端并执行容器清理；真实 Python 子进程取消测试通过 |
| 缺少 task 字段的 HTTP 200 被当成空队列 | 只有显式 task:null 才表示 idle，畸形响应保留 claim_unknown 和原请求键 |
| 验收器忽略新增浏览器/OIDC 配置 | 离线检查 Origin、会话/Agent租约期限、配置开关、OIDC构造和本地依赖；不访问 discovery 或 token endpoint |

## OIDC 独立检查

阅读了 `worker/oidc.py`、`worker/browser_auth.py`、`worker/service.py` 和相关假 IdP 测试，没有发现本次检查范围内的阻断级认证缺陷。确认的边界包括：

- state 与单次浏览器事务 cookie 双绑定，交换前消耗事务；过期与重放不能换取会话。
- S256 PKCE；固定 issuer/audience/RS256；JWK 来自配置 IdP 同主机的 HTTPS 地址，忽略 token 自带密钥 URL。
- nonce、签名、时效和已授权 subject 校验；只映射已存在的本地人员，不根据 email 或 IdP roles 自动提升权限。
- 临时事务 cookie 为 HttpOnly/Lax；应用会话为 HttpOnly/Strict，回调后轮换并撤销原会话。
- 回跳地址固定为 `/`；不回显授权码、access token、refresh token 或 provider 敏感错误，不把回调查询写入访问日志。

该结论属于独立代码检查；没有连接真实企业 IdP，也不能把假 IdP 的 RSA 签名测试称为真实 SSO 部署验收。

## 附件协议最终独立复核

阅读 `worker/artifacts.py`、`worker/service.py`、SQLite v4 表结构及 Agent 客户端上传恢复状态；在本次检查范围内未发现阻断交付的问题。服务端每次上传要求认证 Agent、当前有效租约、当前 SHA/首轮审核和当前 run_id。路径只作为数据库元数据；拒绝绝对路径、父目录、非规范 POSIX 路径与控制字符，不读取服务宿主的同名路径。

每块最多 384 KiB，服务端解码前后均检查大小和规范 base64；每次体验包括旧 run 与部分上传在内最多 100 个文件、64 MiB。两个线程同时预留各 40 MiB 的独立测试中仅一个成功。完成时分块写 SQLite BLOB 并校验总大小及 SHA-256；哈希失败回滚最后一块和完成记录。重复块不可变，乱序上传最终按块序重建，完成审计事件仅产生一次。

结果只能引用同体验、同 run 的已完成文件；第二个引用缺失或重复路径不会留下部分关联、完成体验或结束租约。下载仅对审核、运营、审计等授权角色开放；Agent 自身与审批角色不能借上传身份读取附件。历史证据保持可查。下载使用 `application/octet-stream`、attachment、nosniff 与编码文件名，不内联执行 HTML；真实 HTTP cookie 回归验证未登录及退出后均为 401。

Agent 客户端上传前验证本地文件，持久化摘要/块序号/原请求键；不确定上传仅重放同块，不重跑任务。恢复时重新校验文件摘要与有效租约；未知结果提交沿用原幂等键。服务端成功 ACK 和客户端 manifest 均绑定体验、run、文件路径、大小、摘要与块序号。
