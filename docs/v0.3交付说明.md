# v0.3 完整应用交付

本轮在原爬虫与后端流程基础上补齐浏览器工作台、团队会话、可选 OIDC、Agent 自动执行客户端、受控证据传输，以及本机与 Linux 部署工具。当前版本是可安装、可运行、可由团队操作的单机应用。

代码完成、本机验证和外部上线是三种不同状态。当前没有用户公司的真实 IdP、Credits 部署配置、Agent 镜像或生产域名，因此外部联调不会被记为已经通过。

## 交付范围

| 模块 | 实际交付 |
| --- | --- |
| 原爬虫整合 | Pipeline 调用重构后的本地 fetcher/userinfo；旧 bootstrap 共用持久化队列与数据库 |
| 浏览器工作台 | 登录、概览、项目筛选、证据档案、两轮审核表单、人类体验、维护关系、联系访谈、赞助审批、Credits 台账、复盘和审计 |
| 团队认证 | 独立角色凭据；HttpOnly 会话、精确 Origin/Host、CSRF、退出清理、业务幂等与审批/执行分离 |
| SSO | 可选 OIDC Code + PKCE S256、固定 subject 映射、RS256、issuer/audience/nonce/state 校验 |
| Agent | 自动领取、续租、隔离执行、任务摘要校验、产物传输、结果回传、私有 outbox 与同键恢复 |
| 证据 | GitHub 当前版本快照；Agent 产物分块传输、摘要和租约绑定、受权限控制的附件下载 |
| Credits | 指定源码契约适配、计划预览、显式邀请、提供方绑定、领取与额度核对、未知结果阻止重复创建 |
| 运维 | 幂等初始化、六身份凭据、Windows 隐藏启动/停止与 PID 校验、日志滚动、健康检查、在线备份、Linux systemd/TLS 模板 |
| 质量 | 自动化回归、真实 HTTP/HTTPS、真实浏览器交互、真实 GitHub 只读采集、打包隔离安装与独立审查 |

## 本机使用

当前正式数据目录通过 `artifacts/validation/setup-production.json` 记录，位于本机应用数据目录，不在 OneDrive。Codex/MSIX 可能重定向实际路径，以初始化输出的 root 为准。正式库中的 GitHub 采集记录没有自动通过审核。

```powershell
$appRoot = Join-Path $env:LOCALAPPDATA 'github-sponsorship-production'
python main.py setup-local --root $appRoot
./scripts/start-local.ps1 -Root $appRoot -Python (Get-Command python).Source
```

浏览器入口为 http://127.0.0.1:8765。运营人员使用 `credentials/relationship-operator.token` 登录；技术复核、审批、Credits 执行和审计使用各自文件。不要把访问凭证粘贴到 URL、源码或报告。

停止命令为 `./scripts/stop-local.ps1 -Root $appRoot`，保留数据库和配置。演示使用另一个目录并显式传 -Demo；演示中的业务数字不可作为真实验收依据。

## 外部上线所需输入

1. **Credits**：服务 HTTPS 地址、活动 slug、管理员核实的有效期、PAT 和测试领取账户。配置后执行邀请→领取→到账核对，不能用 mock 替代。
2. **Agent**：专用 Docker/自有执行节点、固定 digest 镜像、准确 SHA 的源码及依赖、所需模型与测试凭证。离线模式不会自行拉取项目或访问在线模型。
3. **团队入口**：运行主机、域名/TLS；使用 SSO 时还需要 IdP issuer/client/subject 映射。
4. **业务样本**：团队实际完成第一轮、产品体验和访谈，并由不同责任人审批和执行。程序提供记录与门槛，不能代替真实体验或生成作者同意。

实现未执行真实发信、Credits 发放或云端发布。文件大小限制与日志滚动不能替代整个数据库、备份及容器输出卷的容量配额。规模超过单机 SQLite 时需要另行设计并发存储和共享会话。
