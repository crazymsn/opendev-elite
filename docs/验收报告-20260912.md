## 本轮修复

- 资格评估读取损坏或非对象 JSON 时改为失败关闭，项目列表、就绪判断和工作流不会因数据库脏数据直接抛出解析异常。
- 备份目标拒绝符号链接、目录 junction 及其父路径中的链接，避免断链绕过“新文件”约束后把 SQLite 写到非预期位置。
- Agent outbox 使用随机、独占的临时文件进行原子保存，并对损坏的状态文件给出明确阻断，避免可预测临时路径被链接重定向或状态异常导致继续执行。
- 兼容认证器拒绝空令牌列表，并把刷新操作绑定到实际验证失败的令牌槽位；辅助类型转换不再吞掉系统级异常。
