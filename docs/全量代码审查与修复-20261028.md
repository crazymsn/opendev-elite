## 本轮已修复

### 安全与权限

- 外部 origin 的新部署不再自动接受固定管理员密码；必须通过 `initial_admin_password` 或 `OPENDEV_INITIAL_ADMIN_PASSWORD` 提供强密码。
- 本地 loopback 和显式 legacy 测试夹具保留兼容路径，生产外部部署不继承该弱默认行为。
- 项目详情的维护者信息改为固定公开字段投影，不再向 reviewer 返回原始 profile 和拒绝联系字段。
- 联系摘要只向 operator 返回，避免财务角色读取联系人运营状态。
- sub-admin 授权要求维护者属于目标项目、关系已确认且未拒绝联系。
- sub-admin 重复授权返回既有 active membership，并校验期限。
- 推荐链接期限按带时区的 ISO-8601 UTC 时间解析和比较。
- 推荐链接创建者不能提交自己的推荐。
- 联系邮箱过滤 `?&=%` 等 mailto 查询注入字符。

### 采集与任务状态

- Search 发现任务的刷新任务携带 `run_id`。
- Search、refresh 和任务完成/失败路径统一尝试收敛 discovery run 状态。
- Trending 错误进入有界重试，而不是直接死信并永久保持 running。
- contact extraction 使用队列指定的 `snapshot_id`，避免乱序任务读取错误版本。
- AI assessment 在 contact extraction 完成后入队，避免 contactability 在依赖未完成时永久写成 unknown。
- AI assessment 拒绝过期或不是当前完整快照的输入。
- 联系人拒绝后立即将项目 summary 置为 `do_not_contact`、priority 0，并屏蔽相关 contact points。
- 联系优先级按作者主页、直接来源、社区入口分层，不再把所有社区链接当作邮箱级优先级。
- README 明文邮箱能够被识别，同时保留示例域名、noreply 和非法地址过滤。
- GitHub rate-slot 已增加独立持久化 lease 记录；过期许可会在新请求预留时回收，正常释放按 lease ID 删除，不再只依赖裸 `in_flight` 计数。
- AI assessment 已增加全景字段、标签置信度、标签证据引用和结构化校验；数据库 schema 升级到 10 并自动添加 `panorama` 列。
- Compose smoke 已启动 Worker 服务；CI wheel 构建后会在干净 venv 安装并执行 `sponsorship-worker --help`。
- sub-admin principal 已携带 active project scope；项目列表、项目详情、项目读取路径会按 scope 过滤；全局账号、指标、Credits、发现运行和全库导出仍拒绝 sub-admin。
- CI 已加入真实 API smoke 入口：有 `GITHUB_TOKEN` 时读取公开仓库，无 token 时输出明确 skipped，不把无凭证环境误报为真实 API 通过。

### 部署与验证

- v0.8 审计脚本从裸 `assert` 改为显式失败检查，`python -O` 不会误报成功。
