# OpenDev Elite v0.7.3 交付说明

2026-09-08。正式采集此前使用匿名 GitHub 配额，370 个待执行任务受到同一次限流等待影响。本版增加本机 GitHub CLI 登录的显式复用，并把认证后的搜索与代码采集严格限定在公开仓库范围。

## 实现

- 本地部署通过运行目录的 `github.local.json` 选择 GitHub CLI；没有该选项就不读取 gh 登录。显式环境变量、私有令牌文件仍可使用，Docker 保留既有配置方式。
- 固定参数调用 gh，不接受自定义命令；令牌只进入服务进程内存。配置和日志不写令牌。选择的凭据来源不可用时启动失败，避免悄悄回到匿名请求。
- 每条发现查询限定 `is:public`。非公开查询在入队前拒绝；引用文字保持原样。搜索返回后核对可见性，异常条目不导入，覆盖记录分别列出原始条目数、接受数与过滤数。
- 仓库刷新先核对元数据。私有、内部、未知或矛盾的可见性不继续读取代码与作者资料，也不写快照。这是采集范围校验，不生成业务排除结论。
- 保留 Fork 发现、零 Stars 项目、版本证据和人工判断边界。标准仍为 `sop-2026-09-v2`，数据库仍为 schema 6。

## 实际验证

- 353 项全量回归通过，75.870 秒。覆盖凭据读取优先级、错误输出保密、显式选择、重复部署、演示隔离、公开查询、异常可见性过滤及刷新前拦截。
- 独立安装环境在源码之外验证 19 个资源/API 路径；50 个运行文件在源码、wheel 与安装目录之间逐字节一致。
- 最终安装版本向 GitHub 发起一次限定公开仓库的真实搜索，接受 1 个公开项目；使用临时隔离库，没有读取代码或写正式业务记录。
- 认证配额验证成功后，仅恢复那 370 个共享匿名限流等待的任务，保留尝试次数、原错误与操作事件。没有统一清空所有重试等待。
- 正式服务已升级。2026-09-08 03:33:28 UTC 核查时，247 个原候选和全部账号保留；共有 239 个维护者候选、92 份快照，最终重启后新增 2 份。该时点实际采集响应的配额为 5,000、剩余 4,956；此值是当时的响应，不是对所有 GitHub 端点的固定承诺。
- 数据库完整性、外键及全部项目/快照的公开可见性依据通过检查。入选评估、审核、体验、联系、访谈、赞助决定、发放与复盘均保持零记录。
- 正式默认管理员登录与退出成功，公开注册关闭。API 与采集器均运行最终安装环境；本轮没有变更页面布局，没有新增浏览器视觉验收声明。

可追溯输出见 [验证记录](verification/v073/README.md)。部署前备份为运行目录 `backups/before-v073-20260908T031858Z`，最终运行环境为 `runtime/venv-v073-final`，旧环境保留。回滚到 0.7.2 前需移走旧版本不识别的 `github.local.json`，详见 [身份配置](GitHub采集身份配置.md)。
