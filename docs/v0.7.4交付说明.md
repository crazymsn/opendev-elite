## 行为

- 身份验收合并启用的 Token 与活跃团队账号，只读取账号 ID 和角色，不读取密码哈希、不登录、不创建默认账号。
- 停用账号不计入。一个多角色账号仍是一个 actor；人类账号不能充当 Agent。账号/Token actor 冲突及无效账号角色明确阻断就绪状态。
- 输出仅报告总数和两类身份的数量，不输出成员 ID、用户名、显示名称或凭据。
- 配置结构通过不等于真实人员已履职，也不证明密码有效或业务闭环完成。数据库 schema 6、入选标准 `sop-2026-09-v2` 不变。
