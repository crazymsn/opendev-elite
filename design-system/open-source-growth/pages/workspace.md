# 工作台覆写

与 landing.md 共享颜色、字体、圆角和动效；保持信息密度适合长期使用。

- 宽屏 236px 侧栏，暖白工作区；移动端导航可横向浏览且账号/退出持续可达。
- 概览突出当前待处理工作。待办数量与列表来自相同服务端资格计算，点选进入对应分类。
- 项目行展示仓库、简介、阶段、受众、负责人和证据时间；不伪造转化率或排行榜。
- 状态含文字与颜色，错误含可恢复动作；数据读取期间 aria-busy，完成后焦点落到主内容。
- 表单保留服务端门槛、错误反馈及幂等重试。新增下一次复盘日期，明确可选条件。
- 详情页导航使用链接语义，避免不具备方向键行为的伪 ARIA tablist。
- SVG 图标不依赖外部资源。公开页面隐藏后不得保留可聚焦元素；退出清空敏感 UI。
